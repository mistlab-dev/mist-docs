> 详细版见 `01-中小厂排产交期-需求整理.md`；本文是**给决策看的一页纸**。

## 一、一句话结论

中小厂的排产/交期问题，**不是缺软件，是缺"看得见 + 提得醒 + 改得动"**。

他们现在用的工具是 **Excel + 微信群 + 人的嘴**。这个组合能跑，但有三处必然断裂：

1. **改一处，乱一片** —— 插一个急单，后面所有日期要手改，漏改一行，车间/仓库/销售拿到三个版本的计划
2. **到期没人主动说** —— 「交期还剩三天才催，神仙都救不了」
3. **数据在交接处丢失** —— 「漏单的本质是信息在交接处丢失」

而所有真实付费行为都指向**轻量、便宜、能手机看**的形态，不指向 ERP/MES/APS。

## 二、需求全景：订单全链路的 7 个断点

### ① 接单：交期靠拍脑袋
- 「生产计划靠**『拍脑袋』**，订单扎堆就停工？物料缺料才紧急采购？**交期承诺没底气，客户催单愁断肠**」
- 「**交期算不准，大单来了不敢接**」
- 客户侧也是乱的：「客户在自己的**订单数量和交期飘忽不定**的情况下，却要求工厂能马上（答复）」——（钣金行业）
- **需求**：接单时给一个**"能不能接 / 最快哪天"**的粗反馈

### ② 排产：Excel 是主力，但会失控
真实用户的 Excel 排产逻辑（来自模板作者与实操帖，**这就是他们的现状**）：
- 加一列 `剩余天数 = 交期日期 - TODAY()`
- 条件格式：`≤3 天`标黄、`<0`标红
- 排产日期按「日产能」逐单顺推：第一单开工=可投产日，完工=开工+数量÷日产能；第二单开工=上一单完工
- **明确写着**：「预留『插单』处理……**急单一多，表格会越来越难维护**」

他们的自评：「Excel 排产**最大的问题不是算不准，而是"一改全盘联动"**……漏改一行，车间、仓库、销售拿到的就是**不同版本的计划**」

- **需求**：改一个地方，**所有人看到的都是同一份**（这是 Excel 结构性做不到的）

### ③ 插单：头号痛点，且普遍没有规则
- 「**90% 工厂处理插单，全凭心情、凭关系、凭谁喊的声音大**」
- 「排产表刚排好，销售一个电话进来说『这个单客户要加急』，**然后整张表就废了**」
- 「客户临时加急，**人工手动调半天，改一处乱一片**，交货期一个接一个违约」
- 量化对比：「人工 Excel 插单重排，往往需要 **2 小时**左右。而轻量化 AI 排产，仅需 **8 分钟**完成全局重新优化」
- **需求**：插单前看到**"会顶掉谁"**，一键重排 + 通知受影响的人

### ④ 物料：停工待料是隐形杀手
- 「**开工缺件，停工待料，齐套『老大难』**……缺料详情识别晚，难响应」
- 「一是**频繁待料，常态化出现停工待料、临时换单、中途停线**」→ 某案例「齐套率从 **55% 提升至 85%** 以上」
- 「**不要把产能 100% 排满，留出 10-15% 的余量**应对插单、设备故障、缺料，整体交付率反而更高」
- 案例：「中山一家设备厂……**待料停工从月均 5 次降到 1 次**」
- **需求**：排产前做**一次轻量的"料齐不齐"校验**（不需要 BOM 级 MRP）

### ⑤ 车间执行：数据抄三遍
- **腾讯文档自家案例原话**：「**工人填、主任抄、生产办公室汇总**」
- 「**纸质工单的核心问题就三个字：看不见**。看不见进度、看不见库存」
- 「工人拿着表格填写，**漏填出错是家常便饭**……当天的报工数据需要**晚上加班录入、第二天分析处理**」
- 正面反例（重要）：**不是工人不用手机**——「工人手边有手机、平板，或者车间有个触摸屏，**干完活顺手（录入）**」
- **需求**：手机 **10 秒报工**，同一份数据不抄第二遍

### ⑥ 提醒：靠人吼、靠微信群
- 「我们现在也有预警——**快到期了，跟单员吼一嗓子**」；「靠人吼、靠微信群、靠每天追着问。结果呢？该晚的还是晚」
- 「绝大多数工厂的预警，**根本不是预警，是倒计时**」
- 某厂现状：「规定**每天由客服部在微信通报当天到期订单的出货情况**」
- 改造后：「**采购提前两天催，不再临到交期才发现**」→ 该厂交期准时率 **65% → 92%**
- 完善的提醒节点设计（可直接采用）：
  - **剩余 5 天** → 提醒跟单员检查进度和物料
  - **剩余 3 天** → 提醒生产主管
  - **剩余不足 3 天** → 自动弹窗
  - **已超期** → 黄字红底
- 「**异常必须当天发生、当天记录**，员工手机就能提交，**系统自动关联订单和责任人**，推送给 PMC 和主管」
- **需求**：**周级提前量 + 挂节点（不是只挂最终交期）+ 多通道推送**

### ⑦ 复盘：责任说不清
- 「每个订单明确**唯一跟单责任人**，人员变动时**书面交接**，避免『以为对方在跟』的真空地带」
- 责任划分规范（可参考）：「以下情形计入计划责任：**在物料、工装、能力未确认的情况下承诺交期**；排产冻结窗口内频繁改版；**插单变更未同步现场准备条件**」
- **需求**：变更留痕 + 谁改的、什么时候改的

## 三、现有玩家全景（这是最重要的部分）

把市场上真实在卖的东西分成 4 层，**空白在哪一眼就能看出来**。

### 第 1 层：Excel 模板（免费 ~ ¥4.99）
**真实在大量流通**，是绝大多数中小厂的现状工具：
- 《订单生产计划排产表（**交期提醒和进度跟踪**）excel, wps 套用模板》
- 《生产计划自动排产排期表（**周末可排休**）》
- 《Excel 排产：**计划实际对比和交期提醒**》
- 《Excel 生产排程模板：按**日产能/交期/合格率**智能排产》
- 《一键排产！**多机台多工序** Excel 自动排产系统》
- 《**37 套 PMC 高效 Excel 模板**》
- 定价形态：公众号免费（关注后取）、模板站按次收费（~¥4.99）、文库类免费预览+付费下载

**它们的天花板（用户自己说的）**：一改全盘联动、多版本、插单难维护、手机上难用、无提醒推送。

### 第 2 层：轻量小工单 / 小程序（**最直接的竞争者**）
这一类**正好坐在我们要做的位置上**：

| 产品 | 定位/亮点 | 备注 |
|---|---|---|
| **企丰小工单** | 东莞配件厂案例：**交期延误从月均 4 次降到 1 次** | 三个堵点：进度黑箱、交期延误、报工手写纸单 |
| **橙子生产通** | **69 元/人/年起**，15 天免费试用，进度看板+扫码报工 | **价格锚点的下限** |
| **蓝狐小工单** | 微信扫码报工，**30 多个行业模板**，管理端电脑统一管 | 车间大屏 |
| **吉客小工单** | 小程序免下载，进度跟踪/一键报工/薪资/库存 | 「几分钟搭好」 |
| **车间报工宝**（盒木科技） | 「**3 秒扫码报工**」，计件/计时，车间大屏+手机双端 | 家纺 MES 出身 |
| **蓝咚小工单** | **线束厂专用** | 行业垂直 |
| **云缝通**（灿屿科技） | **服装厂专用**，裁床/扫码报工/计件计时/品质溯源/薪资 | 行业垂直 |
| **今天排** | **多品种小批量机加工** AI 排产 | 「现场一变，计划跟着变」 |
| **进度小助手** | 通用进度/任务/提醒，非制造专用 | 泛用 |

**共同特征**：微信扫码报工 + 进度看板 + 手机端 + 低价 + 行业模板。
**选型提醒（来自业内）**：「有些系统宣传『自动排班』其实是**伪能力**，**人员请假调班就卡住**，本质还是人工派单」；「小程序方案**依赖车间网络**，无 Wi-Fi 的车间可能卡顿；复杂报表要回电脑后台」

### 第 3 层：零代码平台 / 多维表格（**我们的同类**）
- **简道云**（出现频次最高，73 次）：**免费版 → 付费起价 ¥5000/年**；官方有《交期预警实现方案》《智能交期预警方案》等成熟模板；零代码搭 PMC 系统可「**2 小时**从零搭完」
- **WPS 多维表格 / 飞书多维表格**：免费起步，被大量小厂当作底座；但会膨胀成「**影子系统**」
- **企业微信智能表格**：官方有「**自动化：自动提醒人、催进度**」课程（24 万播放），说明**这个需求是平台级公认的**
- **勤哲 Excel 服务器**：Excel 当低代码底座做订单排产系统（老牌，客户案例含甘特图+表间公式）

**他们的弱点**：简道云起步 ¥5000/年对很多小厂「**估计是不想承受的**」；多维表格要用户自己搭，**没有行业语义**（不懂"工序""机台""齐套"）。

### 第 4 层：ERP / MES / APS（**太重，明确不碰**）
- 金蝶 AI 星空、JVS-APS、慧湃排产、智邦 ERP、泛盾注塑云、数夫（家具）…
- **业内一致的劝退**：「很多项目之所以最后失败，**不是因为功能不够强，而是太复杂、现场根本跑不动**」
- 「**ERP 只管了『记账』的活**，真到插单排产这种要动全盘的事，还得靠人到处拉数据」——上了 ERP 依然乱
- 「生产线还在用 Excel 排工单……**最后这套系统沦为摆设**」，「在我接触的 **200 多家中小制造工厂**里，类似的故事反复上演」

## 四、空白在哪（我们的机会）

把上面四层摆开，空白非常清楚：

```
                    Excel 模板        轻量小工单        零代码平台         ERP/MES/APS
价格                免费~5元          69元/人/年起      5000元/年起         1万~50万+
网页表格能力        强（本地）        弱（固定表单）     强（原生）          中
手机/多人协作        ✗                ✓                ✓                部分
提醒推送             ✗（VBA勉强）      ✓                ✓（要自己配）       ✓
行业语义(工序/机台)  靠人设            固定模板           ✗（要自己搭）       ✓（但太重）
可自己改逻辑         ✓（公式）         ✗（改不动）       ✓（但门槛高）       ✗（要找厂商）
插单"会顶掉谁"       ✗                ✗                ✗                部分（很贵）
```

**三个真空白：**

1. **「插单影响面预演」没人做** —— 轻量小工单没有排产语义，零代码平台要用户自己搭，APS 又太贵太重。这是**最锋利的差异点**。
2. **「表格的可改性 + 系统的提醒力」没人同时给** —— Excel 能改但不会提醒；小工单会提醒但改不动；简道云两头都能但要 ¥5000 起且有学习成本。
3. **「便宜的私有化」** —— 「**一台旧电脑，撑起整个工厂的数字化**……数据 100% 私有……一键部署，无人值守」有真实需求，但市场上主要是 SaaS。

## 五、我们该做什么（结合 mist-docs 现有能力）

**已有能力（已核对代码，可直接复用）**：
- `documents.type = doc|sheet` 两种类型
- **表格公式引擎** `web/src/engine/formula.testable.ts`（SUM/AVERAGE/IF，支持公式引用公式）
- **xlsx 导入**（`import.go: xlsxToSheet`）+ CSV 导出
- 现成 handler：`share.go`、`notification.go`、`template.go`、`webhook.go`、`lock.go`
- 部门/用户/权限/审计体系（`model.go` 里 Department/User/DocPermission/DocAudit）
- **私有化部署**已经是我们的形态

### ✅ 做（P0）
| 功能 | 为什么是它 | 难度 |
|---|---|---|
| **排产表预置模板** | 用户已经在手搓同样三大模块（基础信息/交期提醒/进度跟踪），我们只要把它做成"多人实时 + 不串版本" | 低 |
| **日期语义 + 剩余天数公式** | `=交期-TODAY()` 已是用户习惯；我们的公式引擎直接支持 | 低 |
| **条件高亮（超期红/临期黄）** | 用户自己在 Excel 里就是这么做，迁移零成本 | 低 |
| **分级到期提醒（T-7/T-3/T-1/逾期）** | 「提前三周甚至一个月」；复用 `notification.go` + webhook | 中 |
| **企业微信 / 公众号推送** | 内业一致指向这个渠道；「企微、公众号消息推送」是明确卖点 | 中 |
| **今日待交一屏** | 老板要的不是报表，是"今天该交什么、哪几单要黄" | 低 |
| **Excel 导入导出** | 让他们能把现成排产表搬进来 | 已有 |

### 🔥 优先做差异化（P0+）
**插单影响面预演**：选一张单插进去 → 自动列出**被顶掉的订单 + 各自新交期**。
- 只做**单机/单班组 + 有限工序**，不做全能 APS
- 这是唯一没人做好、且痛点最痛的点（R1）

### ❌ 不做
- 完整 MES / APS / MRP
- 设备数据采集、IoT
- BOM 级物料运算
- 全能进销存

> 依据：「**先解决一个真痛点，别买『全家桶』**……先对着一个点解决，见效快、员工有动力用，再（扩展）」——这条来自踩过坑的生产主管，是最实在的产品建议。

## 六、定价参考（有依据的区间）

| 锚点 | 价格 | 来源类型 |
|---|---|---|
| Excel 模板 | **免费 ~ ¥4.99/份** | 模板站实际定价 |
| 橙子生产通 | **¥69/人/年起** | 小工单实际报价 |
| 模板/SaaS 类小程序 | **几千 ~ 1 万/年** | 定制商报价区间 |
| **简道云付费版** | **¥5000/年起** | 明确写出"很多小公司不想承受" |
| 轻定制（含交期预警规则） | **¥1 万 ~ 5 万** | 定制商报价 |
| 深度定制（对接 ERP/仓库） | **¥5 万起** | 同上 |

**推论**：市场是**两极分布**——低端近乎免费，高端几万起，**中间 1000~5000/年 几乎是真空**。
若我们落在 **¥1000~3000/年/厂**，同时给"提醒能按自己工序改 + 可私有化"，性价比叙事成立。
另：市场对「**交期提醒逻辑能不能按自己的订单/产线/工序改**」有**明确付费意愿**（轻定制 1-5 万就是为这个付的钱）——这正好是"可改公式"的强项。

## 七、政策口子（一条几乎没人用的官方获客通道）

- **文件**：工信部办公厅《「小快轻准」数字化产品和服务**培育指引（2026 年版）**》（2026-07）
- **五大维度**：小型化（**避免功能堆砌**）/ 快速化（**部署周期短、见效快**）/ 轻量化（**支持低代码二次开发，避免厂商锁定**）/ 精准化（**能量化降本增效**）/ 数智化
- **共性要求**：安全稳定可靠 + **价格合理透明**
- **落地机制**：工信部**不发全国统一清单**，指导**各地方分批遴选公布**。已出名单的地区：上海（2025 年度）、咸阳、贵阳（2025 年度）、南昌经开区、珠海政企通…

**为什么重要**：五条里我们**天然占优四条**（价格透明、部署短、不堆功能、低代码可改）。而且**进地方名单 = 拿到中小企业客户的官方可信入口**，值得研究申报路径。

## 九、一页纸决策摘要

**痛点最痛的排序**：插单 → 交期承诺 → 到期提醒 → 停工待料 → 报工/进度可见
